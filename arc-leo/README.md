# Arc Leo Studio prompts

This folder is written by Arc Leo Studio. It holds what each team asked for and the prompt built from it.

- `inputs/<team>/<member>.md`: what each person wrote, one file per person, one section per question
- `prompt/draft.md`: the latest prompt Arc Leo Studio merged from all the teams
- `prompt/locked/vN.md`: a locked version. It never changes. The tag `prompt/vN` marks the commit that locked it
- `project.json`: the project and its teams

Every commit here is authored by the person who made the change. Edit inputs in Arc Leo Studio: changes made to these files
directly are not read back yet.
